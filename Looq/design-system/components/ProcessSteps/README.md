# ProcessSteps

What happens after someone gets in touch: `<ol class="steps steps-4">` of `.step` items, each with a `.step-num`, an `h3` and one sentence.

- Leave `.step-num` empty to number automatically (01, 02…), or write your own (a time, an icon).
- Three or four steps. Start with the first contact and end with what the customer gets.
- Works on light sections and inside `.on-dark` bands (numbers switch to `accent`).
- This is the "what happens next" trust component from the Wave 1 reference: keep it near the main CTA.
