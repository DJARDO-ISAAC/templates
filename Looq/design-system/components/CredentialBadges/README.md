# CredentialBadges

Licences, registrations and memberships the business genuinely holds: a `.badges` list of `.badge` items (icon or official mark, name, optional number). `.logos` is a muted strip of client or partner marks.

- Show only what can be verified, and link to the official register where one exists.
- Typical Ghana credentials by industry are listed in the Ghana conventions guide (ORC, ICAG, GIPC, Real Estate Agency Council, NaSIA, FDA, GTA…).
- Use client and partner logos only with permission and only for real relationships.
