# Tag

A small label that cannot be clicked, used for facts and status on cards: `<span class="tag">`.

- `.tag` (on `surface-2`) is for facts like "20 min" or "Serves 4". `.tag-accent` is for one highlight per card, such as "New" or "Sold out".
- Keep it to one to three words. Use sentence case unless the template's type style says otherwise.
- Never use a tag as a button. Use `.chip` for that.
