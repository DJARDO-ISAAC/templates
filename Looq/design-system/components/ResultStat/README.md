# ResultStat

A measurable outcome: `.stat` with who it was for (`.stat-who`), the number (`.stat-value`) and what it means (`.stat-label`), usually three in a `.stats` row with a short story below each.

- Numbers must be real and explainable. Name the client type and town, not the client, unless they agreed.
- Keep the final number as the text so it reads correctly without JavaScript; `data-count` only animates it.
- Use for results (case studies, impact for nonprofits, pass rates for schools), not for vanity counts.
