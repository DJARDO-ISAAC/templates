# TeamCard

The real people behind the business: `.person` with a `.person-img` (4:5), `.person-name`, `.person-role`, in a `.team` grid. `.person-row` is the compact version with an `.avatar`.

- Use real photos of real staff. If there is no photo, use the compact row with initials rather than a stock face.
- The role line can carry credentials ("ICAG member", "Registered nurse"), but only verifiable ones.
- Link to a bio page or `mailto:` when people are contacted directly (law, real estate, consulting).
