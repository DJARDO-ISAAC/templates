# Testimonial

A real customer's words: `<figure class="quote">` with a `blockquote` and a `figcaption.quote-by` (avatar or initials, name, role, place). `.rating` summarises reviews and links to the source.

- Only genuine reviews, with permission. Never invent ratings, names or counts, and keep the Google rating current.
- Specific beats generic: "approved on the first try" beats "great service".
- Use `.avatar` with a photo when the customer agrees; otherwise initials (`aria-hidden`, since the name is in the text).
- Place testimonials near the decision point (services, pricing, form).
