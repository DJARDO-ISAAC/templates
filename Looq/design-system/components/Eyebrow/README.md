# Eyebrow

The short kicker that sits above every section heading: `<p class="eyebrow">`, followed by an `h2`.

- One to four words. CSS makes it uppercase, so write it in sentence case in the HTML ("How it works").
- The marker before it is `::before`. A template can change its shape (a diamond, dot or bar) but keeps one.
- Colour is `brand-strong`, or `accent` inside `.on-dark`.
- Space it 16px above the heading and 12px above the `lede`.
