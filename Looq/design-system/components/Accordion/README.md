# Accordion

Questions and answers (FAQ) built on native `<details class="acc">` / `<summary>`, with `.acc-ic` as the plus/minus and `.acc-body` for the answer.

- Works without JavaScript. Wrap a set in `data-faq-group` to keep only one open at a time (main.js).
- Write questions the way customers ask them ("How much does registration cost?"), answers in two to four sentences.
- Cover price, timing, location, process, payment (MoMo, bank) and what happens next.
- Open the first item by default only when it answers the question most people ask.
- Add `FAQPage` JSON-LD when a page is mostly questions and answers.
