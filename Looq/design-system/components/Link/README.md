# Link

A standalone text link with an underline that wipes away on hover: `.link` with the label in a `<span>`.

Use it for "View all …" and "Read more" next to a section heading or at the end of a card. Links inside running text are plain underlined `<a>` and do not use `.link`.

- Colour is `brand-strong` on light grounds and `night-ink` inside `.on-dark`.
- The arrow is optional. Use it when the link leads to a list or another page.
- Name the destination ("View all recipes"), never "Click here".
